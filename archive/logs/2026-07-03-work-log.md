## 1. VAD媒介型感情分類モデルの実装

### 目的

計画文「VAD媒介型感情分類モデルへの実装計画」に沿って、`emotion2vec features -> VAD -> Linear -> emotion` の分類経路を追加する。

分類器は予測VADだけを入力にし、推論JSONで `logit_c = bias_c + Σ weight_c,d * vad_d` の寄与分解を出せるようにする。

### 実行前の状態

- `vad_downstream/model.py` には作業開始時点で `VADClassificationHead`, `VADMediatedEmotionClassifier`, `Emotion2vecVADMediatedClassifier` の未コミット変更が入っていた。
- `vad_downstream/data.py` は `.npy/.lengths/.vad` のVAD回帰データのみ対応。
- `.vad` と `.emo` を同時に読む loader、CCC+CE 複合学習、VAD媒介分類CLI、推論JSON、寄与分解は未実装だった。
- 作業開始時点で未コミット変更があった主なファイル:
  - `DEEP_LEARNING_EXPLANATION.md`
  - `tests/test_vad_downstream_model.py`
  - `vad_downstream/README.md`
  - `vad_downstream/model.py`

### 実施内容

- `vad_downstream/data.py`
  - `EMOTION_CLASS_LABELS = ["hap", "sad", "ang", "dis"]` を追加。
  - `EMOTION_CLASS_NAMES_JA = ["喜び", "悲しみ", "怒り", "嫌悪"]` を追加。
  - `load_vad_emotion_dataset()` を追加。
  - `VADEmotionSpeechDataset` を追加。
  - `.vad/.emo/.lengths` の行数一致、`.vad` と `.emo` の `utterance_id` 一致、未知感情ラベル拒否、VAD範囲検証を実装。

- `vad_downstream/emotion_training.py`
  - `compute_vad_emotion_loss()` を追加。
  - `loss = lambda_vad * ccc_loss + lambda_emo * cross_entropy` を実装。
  - VAD CCC と分類 WA / UA / weighted F1 / confusion matrix を返す `evaluate()` を追加。
  - VAD媒介分類checkpoint保存 `save_vad_emotion_checkpoint()` を追加。

- `vad_downstream/train_vad_emotion.py`
  - precomputed emotion2vec features から `VADMediatedEmotionClassifier` を学習するCLIを追加。
  - `--target-dim` デフォルトは `3`。
  - `--lambda-vad`, `--lambda-emo` のデフォルトは両方 `1.0`。
  - checkpointに `model_state_dict`, `target_dim`, `input_dim`, `hidden_dim`, `num_classes`, `class_labels`, `class_names_ja`, loss weights, metadata を保存。

- `vad_downstream/infer_vad_emotion.py`
  - 既存 `vad_downstream.inference` のWAV読み込みとemotion2vec checkpoint読み込み経路を再利用。
  - `WAV -> VAD -> logits/probabilities` のJSON出力を追加。
  - `linear_weights`, `contributions`, `contrast_to_runner_up` を出力。
  - 各クラスの `logit_sum` が対応するlogitと一致する形で寄与を計算。

- `iemocap_downstream/scripts/iemocap_manifest_and_labels.sh`
  - 既存の `ang/exc/hap/neu/sad` 標準4分類をデフォルト `standard4` として維持。
  - `vad4` 指定時だけ `ang/exc/hap/sad/dis` を抽出する設定を追加。
  - `exc -> hap` は維持。
  - `neu -> dis` 置換は実装していない。
  - 再実行時に `train.emo` が追記重複しないよう初期化を追加。

- ドキュメント更新
  - `vad_downstream/README.md`
  - `iemocap_downstream/README.md`
  - 既存変更として入っていた `DEEP_LEARNING_EXPLANATION.md` のVAD媒介説明も現在の実装方針と整合。

- テスト追加
  - `tests/test_vad_downstream_data.py`
  - `tests/test_vad_downstream_emotion_training.py`
  - `tests/test_vad_downstream_train_vad_emotion.py`
  - `tests/test_vad_downstream_infer_vad_emotion.py`
  - 作業開始時点で変更済みだった `tests/test_vad_downstream_model.py` はVAD媒介モデル本体のテストを含む。
